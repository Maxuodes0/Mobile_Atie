# AITE Mobile

Flutter mobile app for the AITE system.

## Requirements

- Flutter SDK
- Android Studio or an Android emulator

## Run

Install dependencies:

```powershell
flutter pub get
```

Run with the online Render backend:

```powershell
flutter run --dart-define=API_BASE_URL=https://full-coding-system-backend.onrender.com
```

If the backend URL changes, replace the value of `API_BASE_URL`.
